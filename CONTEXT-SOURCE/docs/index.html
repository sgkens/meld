Meld.js Documentation

The 2kb micro-frontend engine for building native web components without the build step fatigue.

Get Started View on GitHub

Meld offers fine-grained reactivity, native Shadow DOM encapsulation, and a developer experience focused on standards over abstractions.

Installation

You can install Meld via your package manager of choice, or simply drop it in via CDN.

# Install via npm
npm install meldjs
# Install via yarn
yarn add meldjs
<!-- Import via CDN -->
import { defineMeld } from 'https://unpkg.com/meldjs';

Core Concepts

Meld uses a defineMeld function to create components. State is handled via proxies.

Note: Meld components are just standard HTML Web Components under the hood. They work with any framework. 
import { defineMeld, meldState } from 'meldjs';

defineMeld('my-counter', () => {
  // Reactive state
  const state = meldState({ count: 0 });

  return html`
    <button onclick="${() => state.count++}">
      Clicks: ${() => state.count}
    </button>
  `;
});
