Overview

What Meld includes

Meld is built around platform APIs: Custom Elements, Shadow DOM, template literals, JavaScript proxies, DOM events, and ES modules. The core package exposes the primitives. Plugins extend the component context without increasing the default runtime surface.

Component Boundary

defineMeld registers a custom element and gives each component a Shadow DOM root.

Reactive State

meldState tracks property access and reruns only the effects that depend on changed state.

Template Rendering

meldHtml binds functions to text, attributes, events, refs, raw HTML, and Node output.

Plugin Surface

use installs plugins and exposes helpers such as router, query, portal, a11y, and persist.

Quick Start

Define a component

The setup function returns a DocumentFragment. Reactive template functions update when accessed state changes.

import { defineMeld, meldHtml, meldState } from '@meldjs/meld';

defineMeld('hello-meld', () => {
  const state = meldState({ count: 0 });

  return meldHtml`
    <button onclick="${() => state.count++}">
      Count: ${() => state.count}
    </button>
  `;
});

Core API

Core reference

Export Type Purpose
defineMeld(tag, setup) Function Registers a custom element and runs the setup function when connected.
meldState(object) Function Creates a proxy state object with dependency tracking.
computed(getter) Function Creates a derived getter that updates when dependencies change.
meldHtml Tagged template Creates DOM fragments with reactive text, attribute, event, Node, and raw HTML support.
onMount(fn) / onDestroy(fn) Lifecycle Registers callbacks during component setup.
provide(key, value) / inject(key, fallback) Context Shares values through component ancestry using DOM events.
use(plugin, options) Plugin Installs plugin helpers and component definitions.

Plugins

Plugin index

Router

@meldjs/meld/plugins/router

Hash-based client routing and <meld-view>.

Query

@meldjs/meld/plugins/query

Reactive fetch state for data, loading, error, and refetch.

Portal

@meldjs/meld/plugins/portal

Moves modal and overlay content to document.body.

A11y

@meldjs/meld/plugins/a11y

Live announcements and focus trapping helpers.

Persist

@meldjs/meld/plugins/persist

Synchronizes state into browser storage.

Forms

@meldjs/meld/plugins/forms

Form state and validation helper surface.

Tooling

CLI and editor support

meld-artisan provides scaffolding, local serving, component generation, and type generation. VS Code and LSP work remains tracked separately before marketplace release.

npx meld-artisan init my-app
npx meld-artisan make:component user-card
npx meld-artisan serve
npx meld-artisan types
