# Meld.js VS Code Support

Rich developer tooling for Meld.js web applications, providing syntax highlighting, snippet libraries, and TypeScript server autocompletions.

## Features

- **Syntax Highlighting**: HTML syntax highlighting inside `meldHtml` template literals, CSS inside `meld.theme(...)`, and HTML inside `meld.raw(...)`.
- **Snippets**: Quick boilerplate expansion for defining Meld components (`mcomp`) and styling themes (`mtheme`).
- **Autocompletions & Diagnostics**: Integrates the `meld-lsp` server plugin directly into your workspace TypeScript compiler.

## Installation

This extension is packaged and distributed via the Visual Studio Code Marketplace. Search for **"Meld.js Support"** and click Install.
